# 사용자 제공 로컬 디자인 자료

1. 원본 출처·파일명·해시·키트 버전과 작성 도구 버전을 기록한다. 업로드 파일 자체의 버전 기록을 원격 최신성 증명으로 해석하지 않는다.
2. Sketch 같은 ZIP 기반 자료는 경로 탈출·과대 압축 해제 위험을 확인하고 필요한 JSON만 읽는다. 사용자 원본을 변경하지 않는다.
3. 페이지·심볼 이름/ID·공유 스타일·색상을 검색 가능한 로컬 요약으로 정리한다. 심볼 변형 수와 독립 컴포넌트 종류 수를 구분한다.
4. frame 크기·캔버스 좌표·실제 활성 영역을 구분한다. Sketch 속성을 CSS로 동일 변환했다고 주장하지 않는다.
5. 내장 preview가 표지인지 실제 컴포넌트 화면인지 확인한다. 구조 추출은 시각 렌더링 검증을 대체하지 않는다.
6. 자료는 프로젝트 바깥 개인 경로나 Git에서 제외한 local-assets/에 둔다. 원본·추출 데이터·폰트·미리보기의 공개 저장소 반영은 별도 권한 확인 전 금지한다.

이 공개 저장소는 Sketch 파서나 렌더러를 제공하지 않는다. 설치만으로 로컬 자료가 자동 수집되거나 분석되지는 않는다.
