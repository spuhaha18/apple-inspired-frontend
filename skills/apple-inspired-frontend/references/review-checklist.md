# 검증 체크리스트

각 항목을 PASS / FAIL / 미검증 / 해당없음(사유)으로 기록한다.
- DESIGN.md와 화면 위계·행동·탐색 일치
- 실제 데이터·한글·긴 값·로딩·빈 결과·오류·성공·권한 없음
- 키보드 전 작업·포커스 표시·모달 종료 후 복귀
- label·접근 가능한 이름·읽기 순서·표 헤더
- 실제 색 대비 측정, 라이트/다크·상태별 확인
- 200% 텍스트 확대·리플로우·작은/큰 화면 overflow
- 색 외 상태 표현·위험 동작 구분·중복 제출 방지
- reduced-motion·불투명 fallback에서 기능 유지
- blur/animation 성능 실측
- 폰트·아이콘·Apple 자산 라이선스 확인
- 코드 테스트·브라우저 상호작용 증거 기록
- 실제 스크린샷을 사람 또는 vision 도구로 검토; DOM만으로 시각 검증 대체 금지
- 규제 업무는 별도 데이터 무결성·권한·감사추적 검증

보고에 실제 수행 테스트, 결과, 증거 경로, 미검증 범위를 포함한다.
