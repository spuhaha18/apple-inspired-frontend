# UI 키트와 아이콘 — 프로젝트 적용 가이드

## 자료 선택
- 데스크톱 업무 웹: macOS UI 키트와 HIG sidebar/toolbar/table 원칙을 참고 대상으로 선택한다.
- 모바일·태블릿: iOS/iPadOS UI 키트와 탐색·창 크기 적응 원칙을 참고한다.
- 브라우저의 URL/back, 키보드 탐색, 반응형을 유지한다. OS 창 버튼·가상 키보드·FaceID 화면을 일반 웹에 복제하지 않는다.
- 공식 리소스 목록에서 연결된 파일도 실제 열람 전에는 내부 컴포넌트나 치수를 확인했다고 보고하지 않는다. 버전·출처·열람 수준을 DESIGN.md에 기록한다.

## 아이콘 설계
아이콘의 역할 → 의미 → 상태 → 접근 가능한 이름을 정한 뒤 라이선스가 적합한 세트를 선택한다. 웹에서는 일관된 SVG 크기·선 굵기·currentColor 사용을 검토한다. 장식 아이콘과 동작 아이콘을 구분하며 상태를 아이콘/색만으로 전달하지 않는다.
기호와 글자의 굵기·크기·기준선을 함께 검토한다. SF Symbols의 native 렌더링·애니메이션 API를 CSS와 동일하게 취급하지 않는다. 원본을 사용할 권한이 불명확하면 대체 아이콘을 사용한다.
애니메이션에는 업무상 목적·트리거·종료 조건을 둔다. 반복 효과가 콘텐츠 읽기를 방해하지 않도록 하고 reduced-motion에서는 정적인 상태 표시로 대체한다. 참고 세션의 버전과 구현 대상의 지원 범위를 별도 기록한다.

## 구현 인계
화면별 HIG 원칙 → 실제 열람한 참고 요소 → 프로젝트 컴포넌트 → 상태/접근성 검증을 연결한다. UI 키트는 실행 가능한 React 컴포넌트 라이브러리가 아니다. 치수·효과·상태는 프로젝트 환경에서 검증한다.
