# REVIEW — 모래 작업함 초기 fixture

실제 원본 `evals/fixture/index.html`, `style.css`, `app.js`를 읽은 정적 검토 예시. 코드 변경 없음. 새로운 지우기 버튼 구현 결과에 대한 검토가 아니다.

## 범위·환경
핵심 작업은 제목 검색과 메모 입력이다. 가상 3건, 네트워크/백엔드 없음. 소스 읽기만 수행했고 브라우저/스크린리더/성능은 실행하지 않았다.

## 증거
| ID | 수준 | 위치 | 방법 | 관찰 |
|---|---|---|---|---|
| E1 | 정적 | index.html 검색 section | 요소 읽기 | 검색 label/input은 있으나 명시적인 지우기 버튼이 없음 |
| E2 | 정적 | app.js render | 함수 읽기 | 빈 검색은 전체 결과, 불일치는 결과 없음 텍스트 |
| E3 | 정적 | app.js note-form submit | 처리기 읽기 | 데모 실패 텍스트만 출력, 입력값 초기화 없음 |
| E4 | 정적 | style.css | 규칙 읽기 | 브랜드 토큰/focus-visible 정의, 대비 측정 기록 없음 |

## 발견·권고
| ID | 심각도 | 문제·영향 | 근거 | 최소 권고 | 재검증 |
|---|---|---|---|---|---|
| F1 | 낮음 | 불일치 검색에서 전체 복구는 수동 삭제에 의존 | E1/E2 | 검색 지우기 버튼과 입력 초점 복귀 | 검색→불일치→지우기→전체 결과 |
| F2 | 중간(실서비스 전환 시) | 저장 성공 경로가 없는 데모를 실서비스 저장으로 오인할 수 있음 | E3 | 데모 표시는 유지하고 실제 저장은 별도 API 요구/설계로 분리 | 저장 응답/실패/재시도 통합 테스트 |
F2는 현 데모의 데이터 손실 버그라는 뜻이 아니다. 실제 저장을 제공하지 않는 범위 한계다. 색 대비 실패는 측정하지 않았으므로 결함으로 단정하지 않는다.

## 미검증
실제 클릭/포커스/줄바꿈/상태 낭독, 200% 확대, 대비 계산, 고대비, 브라우저 호환성/성능은 미검증. 다크 테마는 제공하지 않아 해당없음. 접근성 인증/규제 적합성은 판단하지 않았다.

## 후속·인계
국소 변경 승인을 받은 구현 담당은 F1만 수정한다. 브라우저 검토자는 F1과 메모 폼 회귀를 확인한다. F2의 제품 확장은 별도 합의한다. 코드 변경 없음; 이 리뷰는 수정 승인 자체가 아니다.
