# CHANGE — 검색 지우기

실제 Claude v2 파일럿 산출물에서 자체 편집한 인계 예시다. 실제 생성 파일은 로컬 평가 기록에 보존되어 있으며 아래는 읽기 쉬운 독립 예시다. 시각 검증이 완료된 샘플이라는 뜻이 아니다.

## 범위·승인
고정 가상 작업함에서 검색 지우기를 누르면 빈 검색, 전체 3건, 검색 입력 초점을 복구한다. 모드는 작은 변경, 유형은 업무/관리다. 파일럿 프롬프트가 이 국소 구현을 명시 승인했다. 기존 DESIGN은 없다. 브랜드/탐색/데이터 배열/메모 저장 동작은 유지하고 필터 추가·네이티브 검색 × 제거는 제외했다.

## 재사용·결정
index.html/app.js/style.css를 읽고 기존 `render()`, input/button 공통 스타일, brand/paper/ink/space, focus-visible을 재사용했다. HTML에는 `#clear-search`와 `.search-row`, JS에는 click 처리기, CSS에는 wrap과 보조 버튼 스타일을 추가했다.
주 저장 버튼이 이미 있으므로 지우기는 테두리/브랜드 글자의 보조 버튼으로 정했다. 검색 하나만 지우므로 이름은 ‘검색 지우기’다. 버튼은 항상 제공해 빈 검색에서도 같은 동작을 유지한다. 비활성화 자체가 레이아웃을 흔든다는 일반 명제는 근거가 없으므로 설계 이유로 사용하지 않는다. 좁은 화면은 wrap, 키보드 순서는 입력 다음 버튼, 접근 가능한 이름은 보이는 텍스트다.

## 상태·복구
정상/검색 일치/검색 결과 없음에서 같은 지우기 동작을 수행한다. 이벤트는 `click → value='' → render() → focus()`다. 성공은 전체 결과 수로 나타난다. 로딩/서버 오류/권한 제한은 동기 로컬 검색이라 해당없음이다. 긴 결과 제목은 기존 목록 줄바꿈을 유지한다. 메모 실패 처리와 입력 보존은 인접 회귀 대상이다.

## 검증
| 항목 | 수준 | 실제 방법 | 관찰 | 판정 |
|---|---|---|---|---|
| 요구 이벤트 | 정적 | 생성 HTML/JS 읽기 | value 초기화/render/focus 연결 | PASS(정적) |
| 선택자/폼 | 정적 | HTML/JS 대조 | 이름 일치, type=button, 메모 폼 밖 | PASS(정적) |
| 기존 기능 범위 | 정적 | 원본과 생성 파일 비교 | 데이터/메모 처리 유지 | PASS(정적) |
| 클릭/키보드/초점 | 브라우저 | 미실행 | 브라우저 제공 안 됨 | 미검증 |
| 줄바꿈/대비/낭독 | 시각/측정 | 미실행 | 도구 제공 안 됨 | 미검증 |
실행한 셸 명령은 없다. 코드로 예상한 결과와 브라우저 관찰을 구분했다. 정적 검사에서 실패를 보고하지 않았으므로 수정 후 재실행 기록도 없다.

## 인계
코드 변경 완료, 실행/시각 검증 대기. 다음 검토자는 전체 → 일치 → 불일치 → 지우기 → 재검색, Tab/Enter/Space와 입력 초점 복귀, 작은 화면/확대, 메모 실패 입력 보존을 확인한다. 실제 출력과 정적 검사 근거는 `evals/results.md`가 안내한다.
